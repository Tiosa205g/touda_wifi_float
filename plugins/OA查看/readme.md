# OA通知查看插件

查看汕头大学协同办公系统（http://oa.stu.edu.cn）的通知公告，无需登录 OA。

## 功能

1. **查看OA通知公告** — 应用内浏览通知列表（标题 / 发布单位 / 发布日期），支持分页与按发布单位筛选；
   鼠标悬停时整行高亮
2. **通知详情（应用内）** — 双击列表中的通知查看详情：标题 / 发布单位 / 发布日期 / 正文全文；
   **附件清单逐个显示并下载**（保存到本地，悬停整行高亮）；一键**跳转原页面**（浏览器，可选 WebVPN）
3. **新通知标记** — 高于已读水位的显示为红色，支持「检查新通知」一键对比、「全部标为已读」
4. **🔔 定时检查 + Windows 通知** — 后台定时拉取（关闭/5/10/30/60 分钟可配，默认 10 分钟）；
   **软件启动时立即检查一次**（自动检查开启时），不必等首个轮询周期，
   启动即能看到关停期间的新通知；菜单实时显示新通知数量
5. **点击通知直达列表** — 点击通知弹窗直接打开 OA 通知列表（不标记已读，新通知保持红色标记），
   不再弹出中间可点选列表
6. **🗂 提醒记录** — 最近 20 条提醒持久保存，随时逐条追溯到通知详情
7. **打开OA系统** — 一键进入 OA 首页（可选 WebVPN）

## 说明

- 数据来源为 OA 公开通知栏（`/csweb/list.jsp`）与公开详情页，访问失败时自动按「直连 → 系统代理 → WebVPN」三级回退（附件下载同样三级回退）
- 定时提醒用独立的「已提醒水位」去重，与「已读水位」互不影响（列表红色标记不受提醒影响）
- 所有弹窗均置顶于悬浮球之上，不会被悬浮球遮挡
- OA 全文检索接口对未登录用户响应异常（服务端挂起），如需检索请登录 OA 网页使用
- 通知详情页为公开页面，校外访问「打开原页面」可通过 WebVPN

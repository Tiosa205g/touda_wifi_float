# 汕大邮箱助手插件

汕头大学邮箱（校园网账号@stu.edu.cn）应用内收发客户端 + 新邮件通知。

## 功能

1. **📬 收件箱** — 应用内浏览邮件列表（发件人/主题/时间），分页翻阅；鼠标悬停时整行高亮；
   **左右分栏布局**：左侧列表、右侧正文阅读区（可拖动分隔条调整比例），正文充分展示；
   主题/信头超长时**单行省略**（悬停 tooltip 看全文），不挤压正文；
   点击邮件查看正文：**HTML 正文按原排版渲染，内嵌/外链图片正常显示**（白底阅读区，
   cid 引用智能匹配，超宽图自动缩放）；支持附件保存（含内嵌图片）；
   可标记已读/未读、删除邮件
2. **✉️ 写邮件** — 应用内撰写并发送邮件，支持抄送和附件
3. **🔔 新邮件通知** — 后台定时检查（1/3/5/10 分钟可配）；
   **软件启动时立即检查一次**（自动检查开启时），不必等首个轮询周期，
   启动即能看到关停期间的新邮件；菜单实时显示未读数量（如「📬 收件箱（3 未读）」）
4. **点击通知直达收件箱** — 点击通知弹窗直接打开收件箱（单封时自动展开该封邮件），
   不再弹出中间可点选列表
5. **🗂 提醒记录** — 最近 20 条提醒持久保存，随时逐封追溯到邮件
6. **🔔 检查新邮件** — 手动检查一次
7. **📖 邮件客户端设置** — 显示 Outlook 等客户端所需的 IMAP/SMTP 服务器信息
8. **🌐 打开网页版邮箱** — 一键进入网页版（https://m.stu.edu.cn）

## 账号配置

- **默认（推荐）**：直接使用主程序里的校园网账号登录，邮箱密码与校园网密码一致，
  无需额外配置
- **手动**：在「设置」中指定邮箱地址和密码
- 初次使用邮箱需先修改一次校园网密码激活邮箱（校园主页「校内帐号密码修改」）
- 密码仅保存在本机 `config.toml` 中，请勿共享配置目录

## 技术说明（实测结论）

- 邮箱托管于世纪互联 Office 365；IMAP 密码认证已被服务端禁用，插件不走 IMAP
- **收信**：Microsoft Graph 中国云（microsoftgraph.chinacloudapi.cn），
  使用账号密码换取访问令牌（支持刷新令牌缓存）
- **发信**：Outlook REST v2.0（partner.outlook.cn/api/v2.0），
  失败时自动回退 SMTP（partner.outlook.cn:587 STARTTLS）密码发送
- 首次使用「检查新邮件」会记录当前邮件快照作为基线，之后只提醒新增邮件
- 删除的邮件可在网页版「已删除邮件」中找回
- 若账号启用了双重验证，密码直连不可用，请改用网页版邮箱

## 外部客户端服务器信息

- IMAP: partner.outlook.cn:993（SSL）
- SMTP: partner.outlook.cn:587（STARTTLS）
- 登录用户名：完整邮箱地址（name@stu.edu.cn）
